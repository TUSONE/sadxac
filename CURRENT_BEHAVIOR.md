# Славик: текущая версия поведения

Эта страница заменяет прежние рекомендации про физический выход 79%/0 dB,
миграцию общей громкости в музыкальные потоки и приглушение после ответа на 5 секунд.

## Обновление на плате

Остановить Славика через Ctrl+C. Выполнить от tusone:

```bash
cd ~/slavik
git pull --ff-only
bash install-linux.sh
bash set-output-max.sh
bash music-levels.sh reset
./start-gemini-assistant.sh --calibrate-mic
./start-gemini-assistant.sh
```

`set-output-max.sh` поднимает Headphone/Speaker/Playback, физический Pulse sink и
AEC sink до 100%, сохраняет ALSA. Начать с умеренной громкости внешней колонки:
выход будет громче прежнего. `music-levels.sh reset` один раз убирает оставшееся
ослабление музыкального Pulse-потока от прежней миграции. Во время работы голосовые
команды и duck не меняют общие выходы; helper при старте восстанавливает 100% только
если уровень изменился. Это не постоянный watchdog чужих служб.

Калибровка измеряет оба канала и выбирает лучший SNR; при разнице менее 3 dB сохраняет
правый. Слишком слабый или перегруженный канал отвергается. Старый профиль совместим.
Для настройки с музыкой оставить одинаковый уровень музыки в обоих этапах: сначала
молчать, затем говорить с обычного расстояния. При неудаче старый профиль сохраняется.
В Gemini идёт один выбранный канал, не сумма двух микрофонов и не beamforming.

## Разговор и звук

- Непрерывная Gemini Live-сессия и микрофон. RU/EN подсказки распознавания, русский
  ответ по умолчанию. Подсказки не являются запретом других языков на уровне ASR.
- Обращения в любой части фразы: Славик, Славка, Слава, Славуха, Славчуха,
  латинские варианты. Для ошибки в один символ нужен контекст приветствия/команды;
  отдельно Слайк/Слайка также с контекстом. Слава как обычное слово тоже может
  разбудить — пользователь явно запросил этот триггер.
- После обращения музыка приглушается примерно на 27 dB только в музыкальном
  Pulse-потоке; возвращается после фактического окончания буфера ответа, без
  дополнительных 5 секунд. Очередь аудио и около 120 ms буфера учитываются.
- Окно продолжения разговора без повторного имени остаётся 5 секунд, но НЕ удерживает
  музыку приглушённой. После подтверждения запуска музыки окно закрывается сразу.
- Голос стартует на 40%. «Сделай громкость 50», «погромче» — музыка Spotify;
  «говори тише», «громкость твоего голоса» — только голос.
- Приглушение после обращения помогает следующей фразе, но не делает исходное имя
  слышимым до его распознавания. Не добавлен шумовой триггер, который приглушал бы
  музыку без обращения. AEC и исправленный граф 480/48k сохранены.

## Spotify и информация

Spotify Connect бинарник, службу и исправление ручного выбора треков не меняем.
Инструменты возвращают `accepted`, `confirmed`, `unknown`, `failed` отдельно от
человеческого пояснения и краткий `spoken_response`. Потерянное чтение состояния
после принятой паузы/скипа не означает отказ. Повтор с тем же id не выполняется второй
раз. Фактическое соблюдение формулировки Gemini ещё требует голосовой приёмки.

Для play_track модель может передать 3–5 похожих песен. Код проверяет точное название
и исполнителя через поиск и запускает один список URI: запрошенный трек первым.
Неподтверждённые кандидаты и повторы пропускаются. Ошибка поиска подборки не отменяет
запуск основного трека. Это ограниченная очередь, а не бесконечное персональное радио;
сходство по настроению выбирает Gemini, наличие в каталоге проверяет код.
Выбор из плейлиста сохраняет прежний контекст, подборка к нему не добавляется.

`weather` получает Open-Meteo: время, город, текущие условия и прогноз до 7 дней.
По умолчанию используется Ташкент (по выбору пользователя). Город в голосовой просьбе имеет приоритет. Переопределение в ~/.config/slavik/.env:

```bash
SLAVIK_CITY='Ташкент'
SLAVIK_SEARCH_MODEL=gemini-2.5-flash
```

Без Gemini можно проверить источник: `./start-gemini-assistant.sh --weather 'Москва'`.
`web_search` использует отдельный запрос Gemini с Google Search и возвращает источники.
Используется существующий ключ Gemini; доступность и тарификация зависят от аккаунта.
Ответ без источников не считается проверенной свежей информацией. Сетевые ошибки
сообщаются явно; погода не генерируется из памяти модели.

## Приёмка и ограничения

Это переработка приложения вокруг Gemini, не обучение новой модели и не полный
клон экосистемы Алисы: умный дом, звонки, будильники и Яндекс-навыки не реализованы.
Нельзя гарантировать слышимость при любой громкости: нелинейные искажения динамика,
перегрузка микрофона и обрывы графа нельзя исправить списком имён или промптом.
Не добавлены тяжёлый локальный ASR/нейрошумодав на плату с 484 MB RAM.

Проверить на плате:
1. «Слава, как дела?» и «Как дела, Славчуха?» в тишине и при музыке с 50 cm.
2. Музыка возвращается, когда ответ договорён; без обращения уровень не меняется.
3. «Славик, громкость 50» меняет музыку, «Славик, говори тише» меняет голос.
4. Пауза/скип выполняются один раз, ответ соответствует строке `[Инструмент]`.
5. Названный трек первый, следующие из подборки; ручной выбор в Spotify работает.
6. Погода называет нужный город и актуальное время источника.

При сохраняющихся помехах: `bash trace-audio.sh` во время проблемы. Для акустической
проверки после остановки ассистента: `--record-mic` при музыке и собственной речи;
нужны все три WAV, особенно physical-stereo и aec-before-dsp. Аудио сохраняется только
локально по явной команде. Сравнение уровней не доказывает разборчивость речи.
